# Library Management System

A DBMS mini-project built with **Python** and **SQLite**.

## Features
- Add and view books and members
- Search books by title, author or category
- Issue and return books (14-day loan, Rs 2/day fine)
- View currently issued, overdue books and full history
- Database trigger auto-updates available copies

## Database Design
Tables: `members`, `books`, `issues` (with foreign keys)
Also includes 2 triggers and 1 view. See `schema.sql`.

## How to Run
```
python app.py
```
(Python 3 required. No extra libraries needed.)
